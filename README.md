# Pixbeads 拼豆图纸生成器

将任意图片快速转换为标准拼豆图纸，或对已有图纸二次编辑。所有计算均在本地完成，无需网络，保护隐私。

**在线体验**：[Pixbeads](https://k3ay0.github.io/Pixbeads/)

## ✨ 主要功能

| 模块        | 功能                                                                            |
| ----------- | ------------------------------------------------------------------------------- |
| 图片导入    | 拖放/点击导入 JPG/PNG，支持裁剪与 pbds 图纸文件                                 |
| 智能像素化  | 粒度可调（10-200），卡通（主色）/真实（均色）双模式                             |
| 色彩匹配    | Oklab 感知色彩空间最近色匹配，BFS 区域合并去杂色                                |
| 背景移除    | 边界洪水填充自动识别并移除背景                                                  |
| OCR 识别    | 本地自建 ONNX 流水线识别图纸色号，数据不出本机                                  |
| 色号系统    | 内置 MARD / COCO / 漫漫 / 盼盼 / 咪小窝 5 体系 291 标准色，支持自定义色板       |
| 编辑工具    | 画笔 / 吸管 / 橡皮擦 / 区域擦除 / 颜色替换 / 选区系统 / 水平镜像，50 步撤销重做 |
| 专心模式    | 灰度背景高亮当前色，3 种引导模式 + 分区网格线，沉浸式制作                       |
| 3D 体素编辑 | 二维图纸转 3D 体素，对称绘制、图层管理、分层切片导出                            |
| 导出        | 带色号 Key 的 PNG 图纸、颜色统计图、可再编辑的 pbds 工程文件                    |
| 其它        | PWA 可安装、Tauri 桌面端、画布状态持久化、像素风首页物理交互                    |

## 🛠 技术栈

| 技术         | 版本 | 用途                       |
| ------------ | ---- | -------------------------- |
| Vue          | 3.4+ | 前端框架                   |
| Vite         | 5.2+ | 构建工具                   |
| Tailwind CSS | 3.4+ | 样式系统                   |
| Pinia        | 3.x  | 状态管理                   |
| Tauri        | 2.x  | 桌面应用框架               |
| Rust         | -    | 桌面端后端（当前为脚手架） |
| ONNX Runtime | -    | 本地 OCR 图纸识别          |

## 🚀 开发

**前置要求**：Node.js 18+、Bun 或 npm；Rust 仅桌面端需要。

```bash
bun install          # 安装依赖（Bun 推荐，或 npm install）
bun run dev          # Web 端开发（端口 1420）
bun run tauri dev    # 桌面端开发（Vite + Rust）
bun run build        # Web 端构建
bun run tauri build  # 桌面端构建
```

Web 端通过 GitHub Actions 自动部署到 GitHub Pages。
